# 代码结构说明

## 1. 模块职责

### `src/main.cpp`
只负责：
1. GPIO/SPI/蜂鸣器初始化；
2. 分配 3 MiB PSRAM 打印缓存；
3. 启动 `paperang_app()`。

业务逻辑不再放在入口文件中。

### `src/AppState.cpp`
所有跨模块共享的运行状态集中在这里定义，例如：
- `printData / printDataCount`
- `head_temp_c / head_overheat`
- `PaperSta`
- `heat_density`
- 电池 ADC 与自动关机相关状态

对应声明统一放在 `include/AppState.h`，避免过去在多个 `.cpp` 中散落 `extern`。

### `src/Sensors.cpp`
负责：
- 按键走纸
- 电池检测
- 自动关机检查
- GPIO35 NTC 温度读取和换算
- GPIO34 缺纸状态与消抖
- 缺纸/过温/温度传感器故障安全逻辑

安全策略：
- 缺纸：终止当前打印任务，不断点续打；
- 过温：暂停打印，温度恢复后继续；
- 温度传感器异常：禁止继续加热。

### `src/Printer.cpp`
负责：
- 步进电机半步驱动
- 打印头 SPI 数据发送
- STB1~STB6 加热控制
- 正常打印循环
- 打印测试页和 STB 测试

打印循环调用 `PrinterSafetyCheck()`，但不负责温度公式和缺纸去抖实现。

### `src/Paperang.cpp`
负责：
- Bluetooth SPP 接入
- Paperang 数据包状态机
- P2 命令处理
- 576点/行 -> 384点/行缩放
- 标签定位与打印后补走
- APP 查询温度、纸型、打印状态等协议响应

## 2. 配置文件边界

### `include/HardwarePins.h`
只放硬件 GPIO 与蜂鸣器控制。

### `include/PrinterConfig.h`
只放可调参数：
- NTC 参数
- 过温阈值
- 缺纸去抖
- 打印时间参数
- STB 补偿值
- 打印缓存容量

以后调打印深浅或温度阈值优先只改这个文件。

## 3. 本次整理未改变的关键行为

- 正式温度保护仍为 60°C 停、55°C 恢复；
- 温度每 8 行检查一次；
- 正常温度日志最多每秒一条；
- 缺纸每打印行检查；
- 缺纸后废弃当前任务并跳过后续标签定位；
- P2 图像缩放、29 mm 标签固定补走逻辑保持原版本；
- 蓝牙包接收仍保持原工程“接收 CRC 但不校验”的兼容行为。

## 4. 暂未动的历史代码

为了避免一次结构整理引入协议行为变化，以下内容仅标记，不在本次修改：
- `SET_CRC_KEY`、`SET_POWER_DOWN_TIME` 中的历史位移表达式；
- `GET_SN` 后继续进入电池状态返回的历史流程；
- 自动关机 EEPROM 逻辑；
- 原工程中部分协议字段的大小端约定。

这些项后续应分别做功能测试后再修改，不建议与打印安全逻辑同时调整。
